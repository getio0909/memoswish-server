# Security policy

Please report vulnerabilities privately through this repository’s **Security** tab by choosing **Report a vulnerability**.

Include the affected version, platform or feature flags, impact, and a minimal reproduction. Remove real credentials, user data, and private deployment addresses before submitting. If the reporting button is unavailable, open an issue about the missing reporting channel and keep the vulnerability details private.

The maintainers review reports affecting the current pre-1.0 development version on a best-effort basis.
